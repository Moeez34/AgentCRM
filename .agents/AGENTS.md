# AgentCRM — Project Rules

## Git & GitHub

- **Always push to GitHub after every change**, no matter how small — even single-line edits, typo fixes, or config tweaks.
- Every change must be staged, committed with a descriptive message, and pushed: `git add <files> && git commit -m "..." && git push origin main`
- Never leave uncommitted or unpushed changes at the end of a task.
